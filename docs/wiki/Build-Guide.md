# BG Bed — Build Guide / Book Plan

## Working title
**BG Bed — Designing and Building a Wired Smart Massage Bed**

## Goal
A practical, illustrated guide that lets another builder reproduce the project while also understanding the engineering decisions and troubleshooting process.

## Proposed chapters
1. The idea — why build BG Bed
2. System requirements and design philosophy
3. Overall architecture
4. Touch panels
5. The wired RS-485 network
6. Shemi BedBox
7. Ira BedBox
8. Vibration massage system
9. Eight-motor PWM architecture
10. Audio system
11. Local voice control and privacy
12. Power distribution and grounding
13. Diagnostic LEDs and serviceability
14. Firmware organization
15. Communication protocol
16. Building and wiring the hardware
17. Test methodology
18. Failures, surprises and fixes
19. Final installation
20. Operating the finished bed
21. Bill of materials
22. Schematics and pin tables
23. Source code and GitHub
24. Ideas for future versions

## Visual material to collect
- progress photographs
- wiring photographs before enclosures close
- screenshots of panel UI
- controller and PCB close-ups
- RS-485 wiring
- motor placement diagrams
- serial-monitor evidence from important tests
- before/after photos of failed fixes
- final installed system

## Logo direction
Selected direction: concept **#6** from the first BG Bed logo exploration — bed + crescent/moon + flowing wave motif. This should be refined later into a clean master logo suitable for GitHub, PDF cover, panel splash screen and Instructables.
